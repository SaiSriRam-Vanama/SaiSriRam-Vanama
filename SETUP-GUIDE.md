# ⚙️ Setup Guide — Vanama Sai Sri Ram's GitHub Profile

This guide walks you through the one-time setup needed to make every widget
in `README.md` fully live.

---

## 1. File Structure

Place these files at the **root of a repository named exactly like your
GitHub username**:

```
SAISRIRAM-VANAMA/
├── README.md
├── SETUP-GUIDE.md
├── assets/
│   └── banner.svg        ← custom AI-themed header banner (included)
└── .github/
    └── workflows/
        └── snake.yml
```

Repo URL should be: `https://github.com/SAISRIRAM-VANAMA/SAISRIRAM-VANAMA`

If that repo doesn't exist yet:
1. Click **New repository** on GitHub
2. Name it exactly `SAISRIRAM-VANAMA` (this must match your username exactly)
3. Make it **Public**
4. Check **"Add a README file"**, then replace its content with the one here

---

## 2. Commit the Custom Banner

The header of `README.md` points to `assets/banner.svg` — a custom AI-themed
banner (neural-network motif, circuit accents, glowing divider) built
specifically for this profile rather than a generic template. Just commit
the `assets/banner.svg` file included in this project to your repo and it
will render automatically.

Optional: add a `assets/coding.gif` too (any coding-themed gif), referenced
in the About Me section — or delete that line for a GIF-free layout.

---

## 3. Activate the Snake Contribution Animation

The snake is generated by [Platane/snk](https://github.com/Platane/snk), the
officially maintained action for this.

1. **Commit the workflow file** — `.github/workflows/snake.yml` (included)
   to your `main` branch.
2. **Enable GitHub Actions:**
   `Settings → Actions → General → "Allow all actions and reusable workflows"` → Save
3. **Grant write permissions:**
   `Settings → Actions → General → Workflow permissions → "Read and write permissions"` → Save
4. **Run the workflow once manually:**
   `Actions tab → Generate Snake Animation → Run workflow`
5. **Wait ~1 minute.** GitHub creates an `output` branch with:
   - `github-snake.svg`
   - `github-snake-dark.svg`

   Already linked in the README's **🐍 Snake Contribution Animation**
   section — no further edits needed. Refreshes automatically every 6 hours.

6. **Troubleshooting:** if nothing appears after a few minutes, check the
   **Actions** tab for a failed run — usually caused by skipping step 2.

## 5. Profile Summary Cards (Productive Time, Most Committed Day, etc.)

These use the community project
[github-profile-summary-cards](https://github.com/vn7n24fzkq/github-profile-summary-cards)
and work out of the box with just your username in the URL — no setup
required. If the community-hosted version is ever slow or rate-limited,
self-host it via GitHub Actions using the same "generate → push to branch"
pattern as the snake animation (instructions in that repo's README).

## 7. Changing the Color Theme

All stat widgets currently use a **Blue Neon / Tokyo Night** palette to match
the Cyber Glassmorphism theme. To customize:

- GitHub Readme Stats themes: https://github.com/anuraghazra/github-readme-stats#themes
- Streak Stats themes: https://github.com/DenverCoder1/github-readme-streak-stats#themes
- Trophy themes: https://github.com/ryo-ma/github-profile-trophy#themes

Simply swap the `theme=` (or `palette=` for the snake) query parameter in
the relevant image URL inside `README.md`. To restyle the custom banner
itself, edit `assets/banner.svg` directly — it's plain SVG with a couple of
gradients and text elements, easy to recolor.
